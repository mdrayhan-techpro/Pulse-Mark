১. সফটওয়্যার ও পূর্বশর্ত (Prerequisites - কি কি লাগবে?)
=================================================================================
Pulse Mark সফলভাবে চালানোর জন্য আপনার কম্পিউটারে নিচের সফটওয়্যারগুলো থাকতে হবে:

(ক) PHP (Version 8.0 বা তার বেশি):
    - PHP ইনস্টল থাকতে হবে এবং Environment PATH-এ যুক্ত থাকতে হবে।
    - PHP Extensions: pdo_mysql, mbstring, curl, openssl সক্রিয় (enabled) থাকতে হবে।
    - XAMPP / WampServer ব্যবহার করলে এগুলো সাধারণত অটোমেটিকভাবে থাকে।

(খ) MySQL / MariaDB (Port: 3306):
    - ডেটাবেজ সার্ভার চালু থাকতে হবে (যেমন XAMPP-এর MySQL Start করা থাকতে হবে)।

(গ) Python (Version 3.8 বা তার বেশি):
    - ZKTeco USB ফিঙ্গারপ্রিন্ট স্ক্যানার ব্রিজের জন্য পাইথন প্রয়োজন।
    - ইনস্টলের সময় "Add Python to PATH" চেকবক্সে টিক দেওয়া থাকতে হবে।

(ঘ) ওয়েব ব্রাউজার:
    - Google Chrome অথবা Microsoft Edge (ক্যামেরা ও এআই ফেস ডিটেকশনের জন্য সেরা)।

(ঙ) হার্ডওয়্যার (প্রয়োজন অনুযায়ী):
    - ZKTeco Live20R বা সামঞ্জস্যপূর্ণ USB ফিঙ্গারপ্রিন্ট স্ক্যানার (ফিঙ্গারপ্রিন্ট এন্ট্রি ও পাঞ্চের জন্য)।
    - ওয়েবক্যাম (ফেস এন্ট্রি ও লাইভ ক্যামেরা ফেস পাঞ্চের জন্য)।

(২) phpMyAdmin (http://localhost/phpmyadmin) বা যেকোনো MySQL ক্লায়েন্টে যান।

(৪) প্রজেক্টের রুট ফোল্ডারে থাকা `database.sql` ফাইলটি ইম্পোর্ট (Import) করুন।
(৫) ডেটাবেজ পাসওয়ার্ড কনফিগারেশন:
    - প্রজেক্টের রুট ফোল্ডারে `.env` ফাইল খুলুন (যদি না থাকে তবে `.env.example` কে কপি করে `.env` নাম দিন)।

        DB_HOST=127.0.0.1
        DB_PORT=3306
        DB_USER=root
        DB_PASS=B@nR@y#257
        DB_NAME=pulse_mark
    * দ্রষ্টব্য: আপনার লোকাল MySQL পাসওয়ার্ড যদি ফাঁকা থাকে, তবে DB_PASS ফাঁকা রাখবেন।

৪. ধাপ ৩: প্রজেক্ট চালু করার নিয়ম (How to Run)
=================================================================================

পদ্ধতি (ক) - ১-ক্লিকে স্বয়ংক্রিয়ভাবে চালানো (সবচেয়ে সহজ):
----------------------------------------------------------------------
প্রজেক্ট ফোল্ডারে থাকা `run_project.bat` ফাইলটিতে ডাবল ক্লিক করুন।
এটি স্বয়ংক্রিয়ভাবে:
১. ZKTeco হার্ডওয়্যার ব্রিজ (Port 9000)-এ চালু করবে।
২. PHP ওয়েব সার্ভার (Port 8000)-এ চালু করবে।
৩. আপনার ডিফল্ট ব্রাউজারে http://localhost:8000 ওপেন করে দেবে।

----------------------------------------------------------------------
পদ্ধতি (খ) - ম্যানুয়ালি টার্মিনালে আলাদাভাবে চালানো:
----------------------------------------------------------------------
যদি আপনি নিজে আলাদা কমান্ড দিয়ে চালাতে চান:

১ম টার্মিনাল (পাইথন ব্রিজ সার্ভার):
    python zk_bridge.py
    (এটি http://127.0.0.1:9000 এ হার্ডওয়্যার কানেকশন লিসেন করবে)

২য় টার্মিনাল (পিএইচপি ওয়েব সার্ভার):
    php -S localhost:8000
    (এটি ওয়েব অ্যাপ্লিকেশন সার্ভার চালু করবে)

৩য় ধাপ (ব্রাউজারে দেখা):
    ব্রাউজার ওপেন করে ভিজিট করুন: http://localhost:8000

৬. প্রধান ফিচার ও কাজের পরিচিতি
=================================================================================

(ক) Control Panel (অ্যাডমিন সাইড):
    - Central Dashboard: আজকের মোট উপস্থিতি, অনুপস্থিতি ও লাইভ কাউন্টার।
    - Employee Management: কর্মী যুক্ত করা, কর্মঘণ্টা/শিফট ও কাজের দিন নির্ধারণ।
    - Biometric Entry: ZKTeco ইউএসবি ডিভাইসে ৩ বার ফিঙ্গারপ্রিন্ট দিয়ে নির্ভুল এনরোলমেন্ট।
    - Face Entry: ওয়েবক্যামের সামনে দাঁড়িয়ে এআই ফেসিয়াল ল্যান্ডমার্ক ও জীবন্ত মুখ (Liveness) চেক।
    - Agent Management: একাধিক ব্রাঞ্চ বা গেটের জন্য আলাদা এজেন্ট অ্যাকাউন্ট ও মোড নির্ধারণ।
    - Attendance Reports: ফিল্টার সহ বিস্তারিত রিপোর্ট দেখা এবং Excel/CSV আকারে ডাউনলোড।
    - Permission Table: HR Manager ও Supervisor-দের মডিউল ভিত্তিক অ্যাক্সেস নিয়ন্ত্রণ।
    - Audit Logs: সিস্টেমে কে কখন কি কাজ বা পরিবর্তন করেছে তার নিরাপত্তা ইতিহাস।

(খ) Agent Workspace (মাঠপর্যায়/বুথ সাইড):
    - Biometric Attendance: ZKTeco স্ক্যানারে আঙুল ছোঁয়ালে নিমেষে উপস্থিতি গ্রহণ ও সাউন্ড প্লে।
    - Face Attendance: ক্যামেরার সামনে দাঁড়ালে চোখ পিটপিট (Blink Detection) যাচাই করে পাঞ্চ গ্রহণ।
    - Registered Users: ওই বুথে অনুমোদিত কর্মীদের তালিকা পর্যবেক্ষণ।

৭. সাধারণ সমস্যা ও সমাধান (Troubleshooting)
=================================================================================

সমস্যা ১: "Hardware bridge not reachable on port 9000" বা "Sensor Disconnected"
সমাধান:
- আপনার ZKTeco USB স্ক্যানারটি পিসির ইউএসবি পোর্টে প্লাগ ইন করা আছে কিনা চেক করুন।
- `python zk_bridge.py` কমান্ডের টার্মিনালটি চালু আছে কিনা নিশ্চিত করুন।

সমস্যা ২: "Database connection error" বা ডেটাবেজ কানেক্ট হচ্ছে না
সমাধান:
- XAMPP / MySQL সার্ভার চালু আছে কিনা নিশ্চিত করুন (Port 3306)।
- `.env` ফাইলে দেওয়া DB_USER ও DB_PASS আপনার MySQL-এর সাথে মিলছে কিনা দেখুন।

সমস্যা ৩: ব্রাউজারে ফেস ক্যামেরা ওপেন হচ্ছে না
সমাধান:
- ব্রাউজারের অ্যাড্রেস বারের বামে লক (Lock) আইকনে ক্লিক করে Camera Permission "Allow" করে দিন।
- নিশ্চিত করুন অন্য কোনো অ্যাপে (যেমন Zoom বা Skype) ক্যামেরাটি ইতোমধ্যে ব্যবহৃত হচ্ছে না।

সমস্যা ৪: লাইট মুড বা ডিজাইনের পরিবর্তন দেখতে সমস্যা হলে
সমাধান:
- ব্রাউজারে Ctrl + F5 চেপে ক্যাশ ক্লিয়ার করে পেজটি রিলোড করুন।
